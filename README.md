## 3주차
### 제어문
프로그램에서 명령어의 실행 흐름을 제어하는 문장
* 조건문 : 주어진 조건의 참, 거짓을 판단하여 결과에 따른 코드 블록을 실행하는 제어문
* 반복문 : 프로그램에서 특정 코드를 반복하여 실행하는 제어문
* 제어문의 구조 : 순차 구조, 선택 구조, 반복 구조

### if 문
* 단순 if 문 : 조건식을 판단하여 참인지 거짓인지 결정
  - 조건식 평가
  - 조건이 참일 때만 실행
  - 선택적 실행 가능
  - 간결한 구조
    
* if ~ else 문 : 주어진 조건이 참인지 거짓인지에 따라 다른 코드 블록이 실행
  - 조건식에 따른 실행
  - 대체 실행 경로
  - 조건의 다양성
  - 코드 블록
  - 읽기 쉽고 명확한 코드
    
* 다중 if~else 문 : 다양한 조건을 평가하고 여러 코드 블록 중 하나를 선택하여 실행하는 제어문
  - 다중 조건 검사
  - 선택적 실행
  - 순차적 평가
  - 간결한 구조
    
* 중첩 if 문 : if 문 또는 else 문 내부에 다른 if 문 또는 else 문이 포함된 구조
  - 복잡한 조건 처리
  - 순차적 평가
  - 구조의 복잡성
  - 분기의 다양성
 
### 다중 선택문
* switch case 문 : 하나의 변수나 표현식의 값에 다라 여러 가지 선택 사항 중 하나를 선택하여 실행할 때 사용
  - 값에 따른 분기
  - 정수(문자, 숫자) 및 열거형 값만 가능
  - case 값의 유일성
  - break 문의 중요성
  - default 절
 
### 반복문
특정 작업을 여러 번 반복적으로 실행할 때 사용하는 명령문
* while 문 : 주어진 조건이 참인 동안 특정 코드 블록을 반복적으로 실행하는 제어 명령문
  - 동작 원리 : 조건식 -> 코드 실행 -> 조건식 평가 반복 -> 프로그램 종료
 
* do while 문 : 주어진 조건이 참인 동안 블록 내부의 코드를 반복적으로 실행하는 제어 명령문
  - 동작 원리 : 코드 실행 -> 조건식 -> 조건식의 결과에 따른 코드 실행
 
* for 문 : 주어진 조건이 참인 동안 특정 코드 블록을 반복적으로 실행하는 반복 제어문
  - 동작 원리 : 초기화 -> 조건식 -> 증감식
 
* 다중 for 문 : for 문 안에 또 다른 for 문이 포함된 구조 (외부 반복문이 내부 반복문보다 먼저 시작)

### 분기문
* break 문 : 제어 흐름 문장 중 하나로, 반복문 또는 switch 문에서 현재 실행 중인 코드를 즉시 종료하고 해당 블록 바로 다음의 코드로 제어 전달
  - 반복문에서의 break 문 : 해당 반복문의 실행을 즉시 중단하고 반복문 바로 다음의 코드로 제어 이동
  – switch 문에서의 break 문 : case 문이 실행될 때 break 문이 등장하면 해당 case 문을 즉시 중단

* goto 문 : 프로그램의 실행 흐름을 지정된 레이블로 강제적으로 전송하는 구문

### 함수의 개요
* 함수의 개념 : 프로그램에서 특정 작업을 수행하도록 정의된 독립적인 단위
* 함수의 장점
  - 코드의 재사용 용이
  - 모듈화
  - 코드의 가독성 향상
  - 유지·보수의 용이
  - 추상화
  - 코드의 일관성 유지
  - 매개변수와 반환값을 통한 데이터 반환

* 함수의 종류 : C 언어에서 제공하는 함수와 사용자가 직접 만드는 함수로 구분
  – 표준 라이브러리 함수 : printf(), scanf() 등, 사용자가 필요로 하는 다양한 기능을 지원
  – 사용자 함수 : 표준 라이브러리 함수에서 지원하지 않는 기능을 사용자가 각 프로그램에 맞게 직접 함수 생성

### 함수 선언과 정의
* 사용자 정의 함수 : 프로그래머가 특정 작업을 수행하기 위해 직접 만드는 함수
  - 함수 정의 : 사용자 정의 함수를 구성하는 기본 요소 (함수명, 매개변수, 반환형, 함수 몸체)
  - 함수 선언(원형) : 함수명, 반환형, 매개변수의 자료형을 컴파일러에 알려주는 역할
    ```c
    #include <stdio.h>
    int example (int x, char c);  //함수 선언
    
    int example (int x, char c){  //함수 정의
      //실행될 코드
    }
    ```
  - 함수 호출 : 괄호 안에 매개변수의 자료형과 개수, 반환 받을 변수의 자료형을 정확히 작성  
    호출 함수
    ```c
    void greeting(void);  //함수 선언
    int main(void)
    {
      greeting();  //함수 호출
      return 0;
    }
    ```
    피호출 함수
    ```c
    void greeting(void);  //함수 정의
    {
      printf("Hello World!");
      return;
    }
    ```
* 함수의 형태
  - 매개변수와 반환값이 없는 함수 : 호출 시 전달하는 인자가 없고, 호출된 함수의 실행이 완료된 후 반환값을 받지 않는 구조
  - 매개변수가 있고 반환값이 없는 함수 : 함수 호출 시 인자로 전달받은 값을 사용하여 작업을 수행하지만, 함수가 실행된 후 결과를 반환하지 않는 구조
  - 매개변수가 없고 반환값이 있는 함수 : 함수 호출 시 인자로 값을 전달받지 않으며, 함수가 실행된 후 결과를 반환하는 구조
  - 매개변수와 반환값이 없는 함수 : 인자로 전달받은 값을 활용하여 계산 또는 다른 연산을 수행한 후 결과를 반환하는 구조

### 표준 라이브러리 함수

### 변수의 속성과 범위
* 변수의 속성
  - 변수의 범위 : 변수가 프로그램 내에서 접근 가능한 범위를 정의
    * 지역변수 : 함수 내부에서 선언되며, 해당 함수 내에서만 접근 가능 (함수가 종료되면 메모리에서 해제)
    * 전역변수 : 함수 외부에서 선언되며, 프로그램 어디에서나 접근 가능 (프로그램 시작 시 메모리 할당, 프로그램 종료 시 해제)
  
  - 변수의 지속 기간 : 변수가 메모리에 유지되는 기간을 정의
    * 자동 지속 기간 : 함수 호출 시작 시 메모리에 할당, 함수 호출 종료 시 해제 (지역변수)
    * 정적 지속 기간 : 프로그램 실행 시작부터 종료까지 메모리에 유지 (전역변수, static으로 선언된 지역변수)
  
  - 변수의 연결 : 변수의 범위와 수명을 정의하고, 여러 파일에서 변수 접근 가능 여부를 결정
    * 내부 연결 : static 지정자로 선언된 전역변수는 파일 내부에서만 접근 가능
    * 외부 연결 : 일반적인 전역변수는 다른 파일에서도 접근 가능, 다른 소스 파일에서 extern 키워드를 사용하여 접근

* 지역 변수 : 함수 내부에서 선언되는 지역변수는 해당 함수 블록 안에서만 접근 가능
  - 지역변수의 선언과 사용
    * 지역변수는 선언 위치에 따라 그 쓰임이 구별
    * 변수명이 동일하더라도 선언 위치가 다르면 각기 다른 변수로 인식

  - 지역변수의 지속 기간
    * 지역변수가 선언된 블록의 실행이 시작될 때 스택 메모리에 지역변수가 할당
    * 지역변수의 지속 기간은 메모리에 존재하는 시간을 의미

* 전역변수
  - 전역변수의 특징
    * 정의 위치: 전역 변수는 함수의 외부 또는 소스 파일의 상단에 선언
    * 초기화: 전역변수를 명시적으로 초기화하지 않으면 0 또는 해당 자료형의 초깃값으로 자동 초기화
    * 지속 기간: 프로그램의 실행 시작부터 종료까지 메모리에 유지
    * 저장 영역: 일반적으로 전역변수는 메모리의 데이터 영역에 저장
    * 접근 범위: 프로그램의 어디에서나 접근 및 수정이 가능하므로 모든 함수가 해당 변수에 접근 가능

  - 전역변수 사용 시 주의점
    * 여러 함수에서 공유될 수 있으므로 데이터의 동기화나 상태 관리에 주의
    * 남용하면 변수의 사용 범위와 캡슐화를 깨트릴 위험이 있기 때문에 필요한 경우에 만 전역변수를 사용하는 것이 바람직함
    * 여러 파일에서 같은 이름의 전역변수를 사용하면 충돌 발생 가능
      - static 지정자를 사용하여 해당 파일 내에서만 접근 가능한 전역변수로 선언

  - 전역변수의 초깃값과 지속 기간
    * 전역변수는 하나의 함수 호출이 끝나고 다른 함수가 호출되더라도 그 값이 유지
    * 지역변수는 함수 호출이 종료되면 함수 내의 지역변수 자체가 소멸
    * 전역변수는 프로그램 실행 도중 상태를 계속 유지해야 하는 정보를 저장할 때 유용하게 사용 가능
    * 전역변수는 컴파일러에 의해 자동으로 초기화

### 변수의 지속 기간
* 정적 할당
  - 프로그램의 실행 시작 시점에 메모리 할당
  - 프로그램의 실행 종료 시점에 메모리에서 해제
  - 전역변수 및 static 지정자로 선언된 지역변수가 사용된 정적 할당의 예
    ```c
    int globalVar;  // 전역변수
    
    void func(); 
    {
      static int staticVar;  // 정적 할당(프로그램 끝까지 변수의 값 유지)
    }
    ```

* 자동 할당
  - 함수가 호출될 때 메모리 할당
  - 함수가 반환될 때 메모리에서 해제
 
* 저장 유형 지정자
  - auto 지정자 : 자동 변수, 지역변수를 선언할 때 사용
  - register 지정자 : 레지스터 변수, CPU의 레지스터에 변수가 저장
  - volatile 지정자 : 컴파일러에 의해 변수가 최적화되지 않도록 지시
  - static 지정자 : 정적 변수로 선언하면 변수가 초기화될 때 메모리에 할당되고, 프로그램 실행 종료까지 유지

### 가변 매개변수 함수
* 가변 매개변수 : 프로그램을 작성하다 보면 매개변수 호출 시 매개변수의 개수를 정해두지 않고 다양하게 사용할 때 사용되는 매개변수
* 가변 매개변수 함수의 요소
  - ...(ellipsis) : 함수 정의에서 가변 매개변수의 시작
  - va_list : 가변 매개변수 목록을 저장하기 위한 자료형
  - va_start : 가변 매개변수 목록의 시작을 초기화하는 매크로
  - va_arg : 가변 매개변수 목록에서 다음 인자를 가져오는 매크로
  - va_end : 가변 매개변수 처리가 끝났음을 나타내며, 목록을 정리하는 매크로
