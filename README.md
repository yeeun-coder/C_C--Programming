## 3주차
### 제어문
프로그램에서 명령어의 실행 흐름을 제어하는 문장
* 조건문 : 주어진 조건의 참, 거짓을 판단하여 결과에 따른 코드 블록을 실행하는 제어문
* 반복문 : 프로그램에서 특정 코드를 반복하여 실행하는 제어문
* 제어문의 구조 : 순차 구조, 선택 구조, 반복 구조

실습 : [evenOdd.c](https://github.com/yeeun-coder/C_C--Programming/blob/14d71dd90af41c07d65ef86c8d1e80d3b6ef0a9c/03week/evenOdd.c)

### if 문
* 단순 if 문 : 조건식을 판단하여 참인지 거짓인지 결정
  - 조건식 평가
  - 조건이 참일 때만 실행
  - 선택적 실행 가능
  - 간결한 구조
    
* if ~ else 문 : 주어진 조건이 참인지 거짓인지에 따라 다른 코드 블록이 실행
  - 조건식에 따른 실행
  - 대체 실행 경로
  - 조건의 다양성
  - 코드 블록
  - 읽기 쉽고 명확한 코드
    
* 다중 if~else 문 : 다양한 조건을 평가하고 여러 코드 블록 중 하나를 선택하여 실행하는 제어문
  - 다중 조건 검사
  - 선택적 실행
  - 순차적 평가
  - 간결한 구조
    
* 중첩 if 문 : if 문 또는 else 문 내부에 다른 if 문 또는 else 문이 포함된 구조
  - 복잡한 조건 처리
  - 순차적 평가
  - 구조의 복잡성
  - 분기의 다양성

실습 : [lab_5-1.c](https://github.com/yeeun-coder/C_C--Programming/blob/5592193484cfe5132a3315039c27c44c135fb205/03week/lab_5-1.c)
 
### 다중 선택문
* switch case 문 : 하나의 변수나 표현식의 값에 다라 여러 가지 선택 사항 중 하나를 선택하여 실행할 때 사용
  - 값에 따른 분기
  - 정수(문자, 숫자) 및 열거형 값만 가능
  - case 값의 유일성
  - break 문의 중요성
  - default 절
  - 실습 : [switchCase.c](https://github.com/yeeun-coder/C_C--Programming/blob/f8d87203374b671b990c6cb780fbd792ffc7c4d1/03week/switchCase.c)
 
### 반복문
특정 작업을 여러 번 반복적으로 실행할 때 사용하는 명령문
* while 문 : 주어진 조건이 참인 동안 특정 코드 블록을 반복적으로 실행하는 제어 명령문
  - 동작 원리 : 조건식 -> 코드 실행 -> 조건식 평가 반복 -> 프로그램 종료
  - 실습 : [while.c](https://github.com/yeeun-coder/C_C--Programming/blob/5e3fc80b568788bc56f047beecf81660268ff1ce/03week/while.c)
 
* do while 문 : 주어진 조건이 참인 동안 블록 내부의 코드를 반복적으로 실행하는 제어 명령문
  - 동작 원리 : 코드 실행 -> 조건식 -> 조건식의 결과에 따른 코드 실행
 
* for 문 : 주어진 조건이 참인 동안 특정 코드 블록을 반복적으로 실행하는 반복 제어문
  - 동작 원리 : 초기화 -> 조건식 -> 증감식
 
* 다중 for 문 : for 문 안에 또 다른 for 문이 포함된 구조 (외부 반복문이 내부 반복문보다 먼저 시작)
  - 실습 : [for.c](https://github.com/yeeun-coder/C_C--Programming/blob/8743fc65b21857990f281c28d337e9247a5ee0fc/03week/for.c)

### 분기문
* break 문 : 제어 흐름 문장 중 하나로, 반복문 또는 switch 문에서 현재 실행 중인 코드를 즉시 종료하고 해당 블록 바로 다음의 코드로 제어 전달
  - 반복문에서의 break 문 : 해당 반복문의 실행을 즉시 중단하고 반복문 바로 다음의 코드로 제어 이동
  – switch 문에서의 break 문 : case 문이 실행될 때 break 문이 등장하면 해당 case 문을 즉시 중단

* goto 문 : 프로그램의 실행 흐름을 지정된 레이블로 강제적으로 전송하는 구문

### 함수의 개요
* 함수의 개념 : 프로그램에서 특정 작업을 수행하도록 정의된 독립적인 단위
* 함수의 장점
  - 코드의 재사용 용이
  - 모듈화
  - 코드의 가독성 향상
  - 유지·보수의 용이
  - 추상화
  - 코드의 일관성 유지
  - 매개변수와 반환값을 통한 데이터 반환

* 함수의 종류 : C 언어에서 제공하는 함수와 사용자가 직접 만드는 함수로 구분
  – 표준 라이브러리 함수 : printf(), scanf() 등, 사용자가 필요로 하는 다양한 기능을 지원
  – 사용자 함수 : 표준 라이브러리 함수에서 지원하지 않는 기능을 사용자가 각 프로그램에 맞게 직접 함수 생성

### 함수 선언과 정의
* 사용자 정의 함수 : 프로그래머가 특정 작업을 수행하기 위해 직접 만드는 함수
  - 함수 정의 : 사용자 정의 함수를 구성하는 기본 요소 (함수명, 매개변수, 반환형, 함수 몸체)
  - 함수 선언(원형) : 함수명, 반환형, 매개변수의 자료형을 컴파일러에 알려주는 역할
    ```c
    #include <stdio.h>
    int example (int x, char c);  //함수 선언
    
    int example (int x, char c){  //함수 정의
      //실행될 코드
    }
    ```
  - 함수 호출 : 괄호 안에 매개변수의 자료형과 개수, 반환 받을 변수의 자료형을 정확히 작성  
    호출 함수
    ```c
    void greeting(void);  //함수 선언
    int main(void)
    {
      greeting();  //함수 호출
      return 0;
    }
    ```
    피호출 함수
    ```c
    void greeting(void);  //함수 정의
    {
      printf("Hello World!");
      return;
    }
    ```
* 함수의 형태
  - 매개변수와 반환값이 없는 함수 : 호출 시 전달하는 인자가 없고, 호출된 함수의 실행이 완료된 후 반환값을 받지 않는 구조
  - 매개변수가 있고 반환값이 없는 함수 : 함수 호출 시 인자로 전달받은 값을 사용하여 작업을 수행하지만, 함수가 실행된 후 결과를 반환하지 않는 구조
  - 매개변수가 없고 반환값이 있는 함수 : 함수 호출 시 인자로 값을 전달받지 않으며, 함수가 실행된 후 결과를 반환하는 구조
  - 매개변수와 반환값이 없는 함수 : 인자로 전달받은 값을 활용하여 계산 또는 다른 연산을 수행한 후 결과를 반환하는 구조

### 표준 라이브러리 함수
* 라이브러리 함수의 사용법 : 함수 원형 선언 (일반적으로 라이브러리 함수의 원형은 헤더 파일에 포함)
 
* 난수 함수
  - rand() 함수 : 헤더 파일에 정의되어 있는 rand() 함수는 호출할 때마다 0부터 RAND_MAX 사이의 무작위 정수를 반환
  - srand() 함수 : rand() 함수에 의해 생성되는 난수 시퀀스의 시드를 설정하는 데 사용
  - 실습 : [exam7-10.c](https://github.com/yeeun-coder/C_C--Programming/blob/a74f562f738f64cb0254f41f6317aa5ea76f5140/04week/exam7-10.c)
 
* 수학 함수 : 특정 수학적 연산이나 계산으로 수행하는 함수

### 변수의 속성과 범위
* 변수의 속성
  - 변수의 범위 : 변수가 프로그램 내에서 접근 가능한 범위를 정의
    * 지역변수 : 함수 내부에서 선언되며, 해당 함수 내에서만 접근 가능 (함수가 종료되면 메모리에서 해제)
    * 전역변수 : 함수 외부에서 선언되며, 프로그램 어디에서나 접근 가능 (프로그램 시작 시 메모리 할당, 프로그램 종료 시 해제)
  
  - 변수의 지속 기간 : 변수가 메모리에 유지되는 기간을 정의
    * 자동 지속 기간 : 함수 호출 시작 시 메모리에 할당, 함수 호출 종료 시 해제 (지역변수)
    * 정적 지속 기간 : 프로그램 실행 시작부터 종료까지 메모리에 유지 (전역변수, static으로 선언된 지역변수)
  
  - 변수의 연결 : 변수의 범위와 수명을 정의하고, 여러 파일에서 변수 접근 가능 여부를 결정
    * 내부 연결 : static 지정자로 선언된 전역변수는 파일 내부에서만 접근 가능
    * 외부 연결 : 일반적인 전역변수는 다른 파일에서도 접근 가능, 다른 소스 파일에서 extern 키워드를 사용하여 접근

* 지역 변수 : 함수 내부에서 선언되는 지역변수는 해당 함수 블록 안에서만 접근 가능
  - 지역변수의 선언과 사용
    * 지역변수는 선언 위치에 따라 그 쓰임이 구별
    * 변수명이 동일하더라도 선언 위치가 다르면 각기 다른 변수로 인식

  - 지역변수의 지속 기간
    * 지역변수가 선언된 블록의 실행이 시작될 때 스택 메모리에 지역변수가 할당
    * 지역변수의 지속 기간은 메모리에 존재하는 시간을 의미

* 전역변수
  - 전역변수의 특징
    * 정의 위치: 전역 변수는 함수의 외부 또는 소스 파일의 상단에 선언
    * 초기화: 전역변수를 명시적으로 초기화하지 않으면 0 또는 해당 자료형의 초깃값으로 자동 초기화
    * 지속 기간: 프로그램의 실행 시작부터 종료까지 메모리에 유지
    * 저장 영역: 일반적으로 전역변수는 메모리의 데이터 영역에 저장
    * 접근 범위: 프로그램의 어디에서나 접근 및 수정이 가능하므로 모든 함수가 해당 변수에 접근 가능

  - 전역변수 사용 시 주의점
    * 여러 함수에서 공유될 수 있으므로 데이터의 동기화나 상태 관리에 주의
    * 남용하면 변수의 사용 범위와 캡슐화를 깨트릴 위험이 있기 때문에 필요한 경우에 만 전역변수를 사용하는 것이 바람직함
    * 여러 파일에서 같은 이름의 전역변수를 사용하면 충돌 발생 가능
      - static 지정자를 사용하여 해당 파일 내에서만 접근 가능한 전역변수로 선언

  - 전역변수의 초깃값과 지속 기간
    * 전역변수는 하나의 함수 호출이 끝나고 다른 함수가 호출되더라도 그 값이 유지
    * 지역변수는 함수 호출이 종료되면 함수 내의 지역변수 자체가 소멸
    * 전역변수는 프로그램 실행 도중 상태를 계속 유지해야 하는 정보를 저장할 때 유용하게 사용 가능
    * 전역변수는 컴파일러에 의해 자동으로 초기화

### 변수의 지속 기간
* 정적 할당
  - 프로그램의 실행 시작 시점에 메모리 할당
  - 프로그램의 실행 종료 시점에 메모리에서 해제
  - 전역변수 및 static 지정자로 선언된 지역변수가 사용된 정적 할당의 예
    ```c
    int globalVar;  // 전역변수
    
    void func(); 
    {
      static int staticVar;  // 정적 할당(프로그램 끝까지 변수의 값 유지)
    }
    ```

* 자동 할당
  - 함수가 호출될 때 메모리 할당
  - 함수가 반환될 때 메모리에서 해제
 
* 저장 유형 지정자
  - auto 지정자 : 자동 변수, 지역변수를 선언할 때 사용
  - register 지정자 : 레지스터 변수, CPU의 레지스터에 변수가 저장
  - volatile 지정자 : 컴파일러에 의해 변수가 최적화되지 않도록 지시
  - static 지정자 : 정적 변수로 선언하면 변수가 초기화될 때 메모리에 할당되고, 프로그램 실행 종료까지 유지

### 가변 매개변수 함수
* 가변 매개변수 : 프로그램을 작성하다 보면 매개변수 호출 시 매개변수의 개수를 정해두지 않고 다양하게 사용할 때 사용되는 매개변수
* 가변 매개변수 함수의 요소
  - ...(ellipsis) : 함수 정의에서 가변 매개변수의 시작
  - va_list : 가변 매개변수 목록을 저장하기 위한 자료형
  - va_start : 가변 매개변수 목록의 시작을 초기화하는 매크로
  - va_arg : 가변 매개변수 목록에서 다음 인자를 가져오는 매크로

### 배열의 개요
* 변수와 배열 : 변수는 오직 하나의 값만 저장할 수 있기 때문에 복잡한 프로그램을 작성하려면 많은 값을 한꺼번에 저장할 수 있는 공간이 필요
* 배열의 구조 : 여러 데이터를 하나의 이름으로 묶어 관리할 수 있는 데이터 구조
  - 배열 요소: 배열을 구성하는 각각의 항목
  - 인덱스: 배열 요소에 붙어있는 번호
 
* 배열의 특징
  - 배열은 메모리의 연속적인 공간에 저장
  - 배열에 저장된 각 데이터를 요소라고 명명
  - 배열의 각 요소는 인덱스로 접근하며, 인덱스는 0부터 시작
  - 배열의 크기는 배열에 있는 요소의 개수를 표현
  - 배열은 연관된 여러 데이터를 하나의 이름으로 묶어 관리하는 데 유용

* 배열 선언 : 배열 요소의 자료형에 배열명 작성 (대괄호 안에 배열의 크기인 요소의 개수 작성)
  - 배열 요소 자료형: C 언어에서 제공하는 배열의 자료형은 int, float, char, double 등
  - 배열명: 배열명을 사용하여 배열을 참조
  - 배열의 크기: 배열에 몇 개의 요소를 저장할 수 있는지를 나타내는 양의 정숫값


* 배열의 접근과 사용
  - 배열 요소에 접근할 때는 인덱스 사용
  - 배열의 인덱스에는 변수, 상수, 수식을 사용하여 지정 가능
    ```c
    int array[8];  // 배열 요소가 8개인 정수형 배열 선언 및 생성
    int i = 1;
    array[i+3] = 40;  // i+3(0~7애서 5번째)번째 인덱스에서 40을 저장
    ```
  - 배열의 인덱스 범위 초과 : 프로그래밍에서 흔한 오류 중 하나로, 유효한 인덱스 를 벗어난 범위에 접근을 시도할 때 발생

* 배열 초기화 : 배열도 일반 변수처럼 초기화할 수 있으나 초기화해야 하는 값이 여러 개이므로 쉼표와 중괄호 이용
  - 배열 초기화 과정
    ```c
    int arr[3] = {1,2,3};  // 정수형 배열 arr을 1, 2, 3으로 초기화
    ```
     * 초깃값의 개수가 배열 요소의 개수보다 많으면 오류가 발생하므로 주의
     * 배열의 모든 요소에 초깃값을 저장하는 것은 일반적인 원칙이지만, 초깃값의 개수가 배열 요소의 개수보다 작은 경우에도 초기화 가능
       ```c
       int arr[5] = {1,2,};  // 배열 요소가 5개인 배열 arr을 1, 2로 초기화
       // [1,2,0,0,0]
       int arr[5] = {1,2,3};  // 배열 요소가 5개인 배열 arr을 1, 2, 3으로 초기화
       // [1,2,3,0,0]
       ```
  - 배열 초기화의 원칙
    * 배열의 크기를 명시적으로 지정하는 방법
      ```c
      int number[100];  // 크기가 100인 정수형 배열을 선언한 후 초기화하지 않음
      ```
    * 초기화하는 값의 개수에 따라 배열의 크기가 자동으로 결정되는 방법
      ```c
      int number[100] = {0};  // 배열 number의 모든 요소를 0으로 초기화
      ```
    - 배열의 크기
      * 배열의 크기는 곧 배열 요소의 개수를 의미
      * 배열의 크기를 확인할 때는 sizeof 연산자 이용
        ```c
        int arraySize = sizeof(score) / sizeof(score[0]);  // 배열 요소의 개수 구하기
        int arrayBytes = arraySize * sizeof(int);  // 배열의 용량 구하기
        ```

### 포인터의 개요
* 포인터의 개념
  - 데이터가 저장된 메모리의 주소를 지정하는 변수
  - 도서관에서 어떤 책을 찾을 때 책의 위치 정보(포인터)를 알면 해당 책에 직접 접근하여 필요한 정보를 얻을 수 있듯이, 포인터에는 데이터가 저장된 메모리의 위치, 즉 ‘주소’가 저장
  - 컴퓨터에서 메모리는 바이트 단위로 주소가 지정되는데, 이 메모리의 주소를 이용하면 데이터를 저장하거나 값에 접근 가능
  - 포인터를 이용하면 큰 데이터 구조를 다룰 때 데이터 전체를 이동하는 대신 해당 데이터의 주소만을 공유하거나 전달 가능
  - 메모리를 효율적으로 사용할 수 있어 큰 데이터를 효율적으로 관리하고 프로그램의 실행 속도 향상
  - C 언어와 같은 <ins>저수준 언어</ins>에서는 메모리를 직접 관리해야 하는 경우가 많아 포인터의 역할이 매우 중요
  - 임베디드 시스템에서 메모리를 직접 조작하거나 <ins>동적 메모리</ins>를 할당할 수 있으며, 함수(9장)에서는 주소를 참조하는 호출을 구현 가능
 
  - 변수의 메모리 주소
    – char형 변수 G 에 저장된 문자 상수 'A'는 메모리의 특정 주소에 <ins>1바이트</ins> 크기로 저장
    – 메모리는 고유의 주소가 바이트 단위로 구성되며, 이 주소로 메모리에 접근 가능
    – 실제 메모리 주소는 보통 16진수로 표현→ 0x00564, 0x00563, 0x00562와 같은 형태

    - 프로그램에서 변수를 선언하면 C 컴파일러가 비어 있는 메모리 공간을 확보하여 해당 변수가 차지하는 크기에 맞게 저장
    - 메모리 주소는 시스템에 따라 달라질 수 있으며, 메모리 할당이 순차적이지 않음
